OBS 素材工作台 1.0.1 使用说明

一、软件说明

本安装包已经包含：

1. OBS Studio 32.2.1。
2. OBS 内置素材工作台。
3. Media Playlist Source 0.1.3 媒体播放列表插件。
4. FFmpeg 和 FFprobe 素材处理工具。

用户不需要提前安装官方 OBS，也不需要单独安装插件。安装完成后即可使用。

本软件用于正常直播制作和已获得授权的素材处理。请遵守直播平台规则，不要用于规避审核、绕过平台检测或处理没有使用权的内容。


二、安装方法

1. 关闭电脑中正在运行的 OBS。
2. 双击“OBS-Media-Workshop-1.0.1-Setup.exe”。
3. 如果 Windows 显示“未知发布者”，请先核对本说明底部的 SHA-256，再决定是否运行。
4. 安装器会打开中文图形窗口，不需要在黑色窗口中输入命令。
5. 在“安装目录”中填写路径，或者点击“浏览...”选择文件夹。
6. 用户选择的是产品目录，OBS 主程序会安装到“所选目录\obs-studio”。
7. 默认勾选“安装完成后启动 OBS”。不想立即打开时，可以取消勾选。
8. 点击“安装”，等待进度完成。
9. 安装成功后，桌面会出现“OBS素材工作台”快捷方式。

默认产品目录：

%LOCALAPPDATA%\OBS素材工作台

默认 OBS 主程序：

%LOCALAPPDATA%\OBS素材工作台\obs-studio\bin\64bit\obs64.exe

自定义安装时，主程序位置为：

所选产品目录\obs-studio\bin\64bit\obs64.exe

注意事项：

1. 不能直接安装到 C:\、D:\ 等磁盘根目录。
2. 不要选择 Windows 系统目录。
3. 如果所选目录下已有不属于本软件的 obs-studio 文件夹，安装器会拒绝覆盖。
4. 如果目录中已有本软件，安装器会先备份旧版本，再安装新版本。
5. 点击“取消”或在安装开始前关闭窗口，不会执行安装。


三、第一次打开 OBS

1. 双击桌面的“OBS素材工作台”快捷方式。
2. 第一次启动可能出现“自动配置向导”。
3. 可以根据电脑和直播环境完成向导，也可以点击“取消”。
4. 以后可以在 OBS 顶部“工具”菜单中重新运行自动配置向导。

如果 OBS 不是中文：

1. 点击 File。
2. 点击 Settings。
3. 打开 General。
4. 在 Language 中选择“简体中文”。
5. 点击 Apply 和 OK，然后重新启动 OBS。


四、打开素材工作台

1. 打开 OBS。
2. 点击顶部菜单“停靠窗口”。
3. 点击“素材工作台”。
4. 素材工作台会显示在 OBS 中，也可以拖出来单独显示。

素材工作台主要用于：

1. 批量添加本地视频。
2. 裁剪视频的开始和结束时间。
3. 调整分辨率、帧率和画质。
4. 调整音量、淡入、淡出和响度。
5. 添加最多两层图片或视频画中画。
6. 调整画中画大小、位置、透明度和出现时间。
7. 把处理成功的视频加入媒体播放列表源。


五、最快素材处理流程

1. 打开“停靠窗口 -> 素材工作台”。
2. 点击“添加素材”，选择一个或多个本地视频。
3. 点击“选择输出目录”，选择处理后文件的保存位置。
4. 打开“处理参数”页面。
5. 普通素材可先使用默认参数：1280×720、30 FPS、CRF 23、音频 192 kbps。
6. 不需要画中画时，不要勾选画中画 1 和画中画 2。
7. 返回“任务”页面，点击“开始处理”。
8. 等待状态变为“已完成”。
9. 在“输出文件”一栏查看生成的视频。
10. 正式直播前，先播放检查画面、声音、时长和方向。

原视频不会被覆盖。输出文件通常为：

原文件名_processed.mp4

如果已有同名文件，会自动生成：

原文件名_processed_1.mp4
原文件名_processed_2.mp4


六、画中画和透明度

画中画素材可以是 PNG、JPG、WebP、MP4、MOV、MKV 或 WebM 等常见图片和视频。

操作方法：

1. 打开“处理参数”。
2. 勾选“画中画 1”或“画中画 2”。
3. 点击“选择”，添加图片或视频。
4. 设置宽度比例。
5. 设置位置。
6. 设置透明度。
7. 设置出现时间和结束时间。

透明度说明：

0.00：完全透明。
0.25：很淡。
0.50：半透明。
0.75：较明显。
1.00：完全不透明。

这里的透明度会被写入处理后的视频文件。

如果要在直播时调整整个播放列表来源的透明度：

1. 在 OBS“来源”面板选中媒体播放列表源。
2. 右键选择“滤镜”。
3. 在“效果滤镜”区域点击加号。
4. 添加“色彩校正”。
5. 调整“不透明度”。

100 表示完全不透明，50 表示半透明，0 表示完全透明。


七、创建媒体播放列表源

1. 在 OBS 主界面找到“来源”面板。
2. 点击来源面板底部的加号。
3. 选择“媒体播放列表源”。
4. 选择“新建”，输入名称，例如“直播素材随机播放”。
5. 点击“确定”。
6. 在播放列表属性中点击加号，添加多个本地视频。
7. 根据需要调整文件顺序。
8. 点击“确定”保存。

如果来源列表中没有“媒体播放列表源”，请确认打开的是本安装包附带的 OBS，而不是电脑中原来的官方 OBS。


八、随机播放和循环播放

1. 双击“来源”面板中的媒体播放列表源。
2. 勾选“随机播放”。
3. 需要持续播放时，同时勾选“循环播放列表”。
4. 点击“确定”。

顺序播放：关闭“随机播放”。

随机循环播放：同时打开“随机播放”和“循环播放列表”。

只播放一轮：关闭“循环播放列表”。

插件支持播放、暂停、停止、上一条、下一条和重新开始。可以在“设置 -> 快捷键”中给这些功能设置按键。


九、处理完成后自动加入播放列表

1. 先在 OBS 中创建一个“媒体播放列表源”。
2. 打开“素材工作台 -> 处理参数”。
3. 找到播放列表区域。
4. 点击“刷新”。
5. 勾选“完成后加入”。
6. 选择目标播放列表源。
7. 返回任务页面并开始处理。

只有处理和验证成功的视频才会加入播放列表。失败或取消的任务不会加入，相同文件路径不会重复添加。


十、声音设置

音量：

0 dB 表示不增减。
负数降低音量。
正数提高音量。
音量过高可能出现爆音或失真。

音频码率：

普通口播建议 128 到 192 kbps。
音乐或高质量立体声可以使用 192 到 320 kbps。

淡入和淡出：

0 表示关闭。
例如淡入 1.5 秒，声音会在开头 1.5 秒逐渐增强。

响度标准化：

适合让不同来源的视频音量更接近，但会增加处理时间。处理后仍要试听确认。


十一、覆盖安装和升级

1. 先关闭 OBS。
2. 运行新版本完整安装器。
3. 选择原来的产品目录。
4. 安装器发现旧版本后会询问是否覆盖。
5. 确认后，旧 obs-studio 会被移动到带时间戳的备份目录。
6. 新版本安装失败时，安装器会尝试恢复旧版本。

备份目录示例：

obs-studio.backup-20260802-090140-732

确认新版本可以正常使用后，可以手动清理不需要的旧备份。删除前必须关闭 OBS，并确认目录确实位于本软件的产品目录中。


十二、卸载方法

1. 关闭 OBS。
2. 打开安装时选择的产品目录。
3. 双击“卸载OBS素材工作台.cmd”。
4. 等待窗口显示 Uninstall completed.
5. 按任意键关闭窗口。

卸载器会删除当前 obs-studio 安装目录和桌面快捷方式。

带时间戳的旧版本备份需要根据实际情况手动删除。

OBS 用户配置通常位于 %APPDATA%\obs-studio，卸载器不会自动删除，以免误删场景、配置文件和直播设置。


十三、常见问题

问题 1：安装器提示“OBS 正在运行”。

处理方法：关闭所有 OBS 窗口，再打开任务管理器，确认没有 obs64.exe 进程，然后重新安装。

问题 2：安装器提示目录中的 obs-studio 不属于本软件。

处理方法：更换一个空目录。不要让安装器覆盖其他 OBS 或个人文件。

问题 3：安装完成后桌面没有快捷方式。

处理方法：打开所选产品目录，进入 obs-studio\bin\64bit，双击 obs64.exe。也可以手动给该文件创建快捷方式。

问题 4：找不到素材工作台。

处理方法：点击 OBS 顶部“停靠窗口 -> 素材工作台”。

问题 5：找不到媒体播放列表源。

处理方法：确认打开的是桌面“OBS素材工作台”快捷方式。不要打开电脑中另一套官方 OBS。

问题 6：素材处理失败。

处理方法：检查输入文件是否损坏、输出目录是否可写、磁盘空间是否充足，并查看“帮助 -> 日志文件 -> 查看当前日志”。

问题 7：Windows 提示未知发布者。

处理方法：本安装器尚未做商业代码签名。请从可信交付目录取得文件，并核对 SHA-256。


十四、正式直播前检查

1. 检查所有素材是否拥有使用权。
2. 检查画布和输出分辨率。
3. 检查横屏或竖屏方向。
4. 逐个检查画面、声音和时长。
5. 检查随机播放和循环播放。
6. 测试上一条、下一条、暂停和停止。
7. 检查来源透明度和画面层级。
8. 先做一次本地录制测试。
9. 再进行平台测试推流。
10. 不要在截图或日志中暴露直播密钥、Token、Cookie 和账号信息。

安装器文件：

OBS-Media-Workshop-1.0.1-Setup.exe

文件大小：

350,560,256 字节

SHA-256：

A26FEA2196DC1E1AC3A8D1CD35FD0E459692FD80065F5D5661EF25AC87A74A65

PowerShell 校验命令：

Get-FileHash .\OBS-Media-Workshop-1.0.1-Setup.exe -Algorithm SHA256

如果计算结果与上面的 SHA-256 不一致，不要继续安装。
